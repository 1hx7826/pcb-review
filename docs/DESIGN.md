# 布线间设计方案

沿用STM32/CET6的本地React + TypeScript + Vite开发、独立数据、验证后准备发布副本的流程。本轮本地制作，未注册托管站点。

色彩：底色 #F2F5F6，纸面 #FFFFFF，文字 #203A43，主操作 #08796B，铜色 #BD7945，分界 #DCE5E7。字体使用系统等线/微软雅黑，数字用系统sans-serif，不依赖在线字体。

桌面采用左侧固定导航、右侧学习工作区。首页左边提供继续学习和课程分组，右边用可切换铜层/阻焊/丝印的原创SVG解释PCB对象。铜色用于焊盘，绿色用于板与学习操作。阅读页保持正文左对齐，约36个汉字行宽，步骤显示动作、原因和判据。手机改为单列、固定底部导航。

实现前复核：不把26节铺成同样的营销卡片，不添加假打卡或虚构成绩。保留真实课号19/22的缺失信息。插图是教学示意而非真实工程渲染。使用frontend-design指导做结构、焦点、响应式和截图自检。
